# 📘 Curso de HTML5 e CSS3 – Curso em Vídeo

Este repositório foi criado para organizar e acompanhar meus estudos no **Curso de HTML5 e CSS3** do **Curso em Vídeo**, ministrado pelo professor **Gustavo Guanabara**.

O objetivo deste curso é ensinar, do zero, os fundamentos do **desenvolvimento web**, abordando a criação da estrutura de páginas com **HTML5** e a estilização visual com **CSS3**, seguindo boas práticas e padrões modernos da web.

---

## 🎯 Sobre o curso

O curso é totalmente focado em iniciantes e evolui de forma gradual, explicando conceitos teóricos e aplicando-os na prática por meio de **exercícios**, **desafios** e **projetos simples**.

Durante o curso, são abordados temas como:

* Estrutura básica de um site
* Tags e semântica do HTML5
* Textos, imagens, links e listas
* Formulários
* Estilização com CSS3
* Cores, fontes e layouts
* Box Model
* Responsividade básica
* Boas práticas no desenvolvimento web

---

## 📂 Organização do repositório

Os arquivos estão organizados de forma modular, acompanhando a estrutura do curso.

### 🔹 Módulos

Cada módulo representa uma etapa do curso e está organizado da seguinte forma:

* `Modulo_1`
* `Modulo_2`
* `Modulo_3`
* `Modulo_4`

Dentro de cada módulo estão os exercícios práticos realizados durante as aulas.

### 🔹 Exercícios

Os exercícios estão separados em pastas numeradas, seguindo o padrão:

* `ex001`
* `ex002`
* `ex003`
* `ex004`
* ...

Cada pasta de exercício contém os arquivos HTML e/ou CSS relacionados à aula correspondente.
